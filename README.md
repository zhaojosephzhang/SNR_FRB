# SNR_FRB_Datasets_reproduction

This repository contains the processed datasets and figure-reproduction materials associated with the paper:

> Zhao Zhang et al. (2026),
> *Probing the Dispersion and Rotation Measure Contributions from Supernova Remnants in Fast Radio Burst Source Environments with 1D SNR Simulation*,
> The Astrophysical Journal.

---

# Overview

This repository provides the data products used to generate the figures presented in the paper, including:

- Dispersion Measure (DM) evolution
- Rotation Measure (RM) evolution
- Optical depth calculations
- Theoretical benchmark comparisons
- Figure-reproduction scripts

The deposited datasets are derived from post-processing of 1D supernova-remnant simulations and are intended to allow readers to reproduce the published figures without rerunning the full simulations.

---

# Repository Contents

## FRB_SNR_Zhang_2026_for_Zenodo.zip

Main data package containing:

### DM_RM_data

Processed time-series data for:

- DM evolution
- RM evolution
- shocked region contributions
- unshocked ejecta contributions
- circumstellar medium (CSM) contributions

as well as scripts and materials used to reproduce the DM and RM figures.

---

### optical_depth_data

Processed optical-depth calculations including:

- Free-free absorption optical depth
- Thomson scattering optical depth
- Total optical depth

for different progenitor models and evolutionary stages.

---

### DM_benchmark_data

Comparison datasets between simulations and theoretical models:

- Yang & Zhang (2017)
- Piro & Gaensler (2018)
- Zhao et al. (2021)

used in the benchmark-comparison figures of the paper.

---

## SNR_FRB.ipynb

Jupyter notebook used for:

- reading simulation outputs
- calculating DM, RM, and optical-depth quantities
- generating benchmark comparisons
- producing publication figures
- exporting Zenodo-ready datasets

# Data Products

The deposited datasets include:

- DM(t)
- RM(t)
- dDM/dt
- d²DM/dt²
- Optical depths
- Shocked-region properties
- Electron-density diagnostics
- Benchmark model predictions
- Figure-reproduction materials

All quantities are stored in machine-readable CSV format.

---

# Reproducing Figures

The datasets include CSV tables and figure-reproduction scripts.

Readers can reproduce the published figures by running the supplied Python scripts or the accompanying Jupyter notebook:

```bash
jupyter notebook SNR_FRB.ipynb
```

or

```bash
python reproduce_xxx.py
```

for the corresponding figure.
